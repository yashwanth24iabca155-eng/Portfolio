# BCA Student Portfolio

A modern, responsive 4-page portfolio website for a BCA student with an interest in **AI, Machine Learning, Web Development and UI/UX**.

## Pages

- `index.html` — Home / hero section, focus areas and highlights
- `about.html` — About, skills, learning direction and education timeline
- `projects.html` — Selected projects and technology tags
- `contact.html` — Contact details and front-end contact form

## Features

- Responsive desktop, tablet and mobile layouts
- Dark/light theme switch with `localStorage`
- Mobile navigation menu
- Scroll-reveal animations
- Subtle cursor glow and animated portfolio card
- No framework required
- No database required
- GitHub Pages compatible
- Easy to customize with your own details

## Customize before uploading

1. Replace `Your Name` and the `YN` initials.
2. Add your college name, course details and graduation year.
3. Update email, GitHub and LinkedIn links in `contact.html`.
4. Replace the demo project titles/descriptions/links with your actual work.
5. Add your resume PDF and profile photo to `assets/` when ready.

## Run locally

Open `index.html` directly in a browser, or use a local server such as VS Code Live Server.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save and open the generated GitHub Pages URL.
